# API reference

All errors use this envelope:

```json
{"error":{"code":"VALIDATION_ERROR","message":"Request validation failed","details":[]}}
```

Amounts are returned as strings with two decimal places. Request bodies reject unknown fields. Account and transaction timestamps are generated by PostgreSQL.
Unsupported methods return `405 METHOD_NOT_ALLOWED`; transactions have no update or delete operation.

## Create an account

`POST /accounts`

Body: `{"name":"Alex Morgan"}`

Success (`201`): `{"id":1,"name":"Alex Morgan","balance":"0.00","created_at":"2026-10-27T10:00:00Z"}`

Errors: `400 VALIDATION_ERROR` for a missing/blank name, malformed body, or unknown field; `500 INTERNAL_ERROR` for an unexpected failure.

```bash
curl -i -X POST http://localhost:8000/accounts -H "Content-Type: application/json" -d '{"name":"Alex Morgan"}'
```

## Get an account balance

`GET /accounts/{account_id}/balance`

Success (`200`): `{"account_id":1,"balance":"50.00"}`

Errors: `400 INVALID_ACCOUNT_ID` for a malformed or non-positive ID; `404 ACCOUNT_NOT_FOUND` if the account does not exist; `500 INTERNAL_ERROR` for an unexpected failure.

```bash
curl -i http://localhost:8000/accounts/1/balance
```

## Add a transaction

`POST /accounts/{account_id}/transactions`

Body: `{"type":"credit","amount":"50.00","description":"Opening deposit","reference_id":"deposit-001"}`. `type` is `credit` or `debit`; amount must be positive and have at most two decimal places.

Success (`201`): `{"id":1,"account_id":1,"type":"credit","amount":"50.00","description":"Opening deposit","reference_id":"deposit-001","created_at":"2026-10-27T10:00:00Z"}`

Errors: `400 INVALID_ACCOUNT_ID` for a malformed account ID; `400 VALIDATION_ERROR` for an invalid body, transaction type, or amount; `404 ACCOUNT_NOT_FOUND`; `409 DUPLICATE_TRANSACTION` when the reference is already used on this account (the `error.details` array contains `existing_transaction`); `422 INSUFFICIENT_BALANCE` for an unaffordable debit; `500 INTERNAL_ERROR` for an unexpected failure.

```bash
curl -i -X POST http://localhost:8000/accounts/1/transactions -H "Content-Type: application/json" -d '{"type":"credit","amount":"50.00","description":"Opening deposit","reference_id":"deposit-001"}'
```

## Get transaction history

`GET /accounts/{account_id}/transactions?type=&page=&limit=`

Query parameters: `type` is optional (`credit` or `debit`); `page` defaults to `1`; `limit` defaults to `10` and has a maximum of `100`. Page and limit must be positive integers. Results are ordered latest first by `created_at`, then descending transaction ID.

Success (`200`):

```json
{"data":[{"id":1,"account_id":1,"type":"credit","amount":"50.00","description":"Opening deposit","reference_id":"deposit-001","created_at":"2026-10-27T10:00:00Z"}],"pagination":{"page":1,"limit":10,"total_records":1,"total_pages":1}}
```

Errors: `400 INVALID_ACCOUNT_ID` for a malformed account ID; `400 VALIDATION_ERROR` for an invalid `type`; `400 INVALID_PAGINATION` for invalid page or limit; `404 ACCOUNT_NOT_FOUND`; `500 INTERNAL_ERROR` for an unexpected failure.

```bash
curl -i 'http://localhost:8000/accounts/1/transactions?type=credit&page=1&limit=10'
```

## Transfer between accounts

`POST /transfers`

Body: `{"from_account_id":1,"to_account_id":2,"amount":"25.00","description":"Shared expenses","reference_id":"transfer-001"}`. The source and destination must differ. The reference ID must not already exist on either account.

Success (`201`): `{"from_transaction":{"id":2,"account_id":1,"type":"debit","amount":"25.00","description":"Shared expenses","reference_id":"transfer-001","created_at":"2026-10-27T10:00:00Z"},"to_transaction":{"id":3,"account_id":2,"type":"credit","amount":"25.00","description":"Shared expenses","reference_id":"transfer-001","created_at":"2026-10-27T10:00:00Z"}}`

Errors: `400 VALIDATION_ERROR` for invalid fields, amount, or identical account IDs; `404 ACCOUNT_NOT_FOUND` if either account does not exist; `409 DUPLICATE_TRANSACTION` if the reference exists on either account; `422 INSUFFICIENT_BALANCE` if the source cannot cover the transfer; `500 INTERNAL_ERROR` for an unexpected failure. Both ledger entries and balance changes commit or roll back together.

```bash
curl -i -X POST http://localhost:8000/transfers -H "Content-Type: application/json" -d '{"from_account_id":1,"to_account_id":2,"amount":"25.00","description":"Shared expenses","reference_id":"transfer-001"}'
```
